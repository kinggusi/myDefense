## 실행

Feature Test Hub의 `P2-2-3`은 단일 `Assets/Scenes/Battle.unity` 진입점을 사용한다. 테스트는 각 Stage마다 새 `P22-MUT-S{1..5}-<unique>` 세션으로 격리한다. 테스트 Scene 추가나 production Build Settings 변경은 없다.

같은 canonical 데이터의 Spring **local profile**을 8082에 실행하고 기존 Daily 창을 종료한 뒤, 이 브랜치 폴더에서 실행한다.

```powershell
.\scripts\Start-P22Daily.ps1 -Content MUT -Stage 1
```

S2~S5는 이전 창 종료 후 `-Stage 2`~`-Stage 5`로 각각 실행한다. 새 빌드는 `-ExePath 'C:\Build\Client.exe'`로 명시한다. 기본 R3 빌드 위치, API/hash preflight, 정상 Kidnap 확인, Reset, 로그 저장 방식은 [배양 구역 실행 절차](P2-2-2.md)를 따른다. 이 런처는 솔로 `dev-daily` Host만 실행하며 POST하지 않는다.

수치는 `daily-battle-stage.json` 기준이며 원본 Balance를 수정하지 않는다. 감소율은 현재 Wave 동안 Player 1 공격 Snapshot에 적용한다.

| S2 | 4 / 150초 | NONE → 공속 -10% → 공격력 -10% → 공속 -15% | W4 |

| S5 | 7 / 240초 | 공속 -20% → 공격력 -20% → 공속 -25% → 공격력 -25% → 공속 -25% → 공격력 -25% → 공속 -30% | W7 |

1. 실제 Client 로그에 서버 Snapshot 적용 완료가 있는지 확인하고 정상 Kidnap을 최소 1회 사용한다. P1 Gold·보드·피해만 변화하고 P2는 계속 비활성이어야 한다.
2. 같은 Alien을 유지해 Wave 전환 시 공격 간격/피해 변화를 비교한다. 공명·Mutation 변경 없이 비교해야 한다. 예: 원래 초당 1회라면 공속 -10% 동안 초당 0.9회, 간격은 약 1.11초다.
3. 공격력 감소는 직접 공격 및 TOXIC Tick·GIANT Splash의 기초 피해에도 반영돼야 한다. 기존 `Show P1 Fixture`의 ID 29 + TOXIC/GIANT를 각각 새 세션에서 사용해 확인한다.
4. 감소가 매 프레임 중첩되지 않아야 한다. 다음 Wave는 원래 서버 Snapshot에서 다시 계산되고, Wave 종료/매치 종료에는 기본값으로 복원돼야 한다.
5. 마지막 Wave에 Boss 1마리가 P1 Lane에서 Spawn·순환·패턴 실행한다. 공용 Boss Lane과 별도 Boss 타이머는 사용하지 않는다.
6. 최종 Boss와 잔존 적을 제거하면 CLEARED 한 번, Boss Kill 한 번만 인정해야 한다. 이미 죽은 Boss/Monster를 재타깃하거나 중복 Splash/Kill 처리하면 FAIL이다.
7. 전체 제한시간은 Wave 전환마다 초기화되지 않는다. 별도 무소환 세션에서 timeout FAILED를 확인한다. 화면비/환경/Effect 가독성과 반복 실행 시 프레임/잔존 상태를 기록한다.

## 남은 게이트

- 정상 Kidnap 구성의 S1~S5 난이도 평가. 완료한 Fixture 기능 smoke로 대신하지 않는다.
- TOXIC의 실제 Tick, GIANT 주변 Splash HP 차분, 실제 발사 간격의 정량 검증. 현재 소비 Snapshot/직접 Hit sink 테스트로 대체하지 않는다.

- User/System trusted 입장/결과 Adapter 주입 후 Daily Result E2E. 현재 fixture runId는 `dev:<Session>`이고 서버 입장 runId가 아니므로 결과는 pending으로 유지한다. pending Summary 수동 POST 금지.
- 최종 아트 교체와 실기기 성능 확인.

Git 자동 생성 변경 5개 승인 후 원복 완료, PR 게시 미완료와 테스트 프로세스 종료 내역은 [배양 보고서 Git 가드](P2-2-2.md#git-가드-및-인계-2026-09-15)를 따른다. 이번 stage/commit/push는 0이다.
