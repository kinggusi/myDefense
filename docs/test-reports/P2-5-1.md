## 사용자 검증 절차

1. Unit 탭의 `신화 교배` Shortcut에서 슬롯 상태와 보상 준비 배지가 표시되는지 확인한다.
2. Main과 Shop에는 중복 교배 Shortcut이 없는지 확인한다.
3. `신화 교배` 화면에서 슬롯 해금·가속·수령 기능이 모두 제공되는지 확인한다.
4. Slot 1은 기본 AVAILABLE, Slot 2/3은 정책에 맞는 해금 상태인지 확인한다.
5. Slot 2는 Level 30 또는 Diamond 5,000, Slot 3은 Diamond 10,000으로 해금되는지 확인한다.
6. 서로 다른 보유 MYTHIC 2종을 선택하고 교배를 1회 시작한다.
7. 시작 후 결과 Alien이 수령 전에는 노출되지 않는지 확인한다.
8. 같은 부모가 다른 BREEDING/REWARD_READY Slot에서 다시 선택되지 않는지 확인한다.
9. 교배 중인 부모도 상세 조회·강화에 사용할 수 있는지 확인한다.
10. 남은 시간이 `HH:MM:SS`로 표시되고, 10분당 Diamond 100 단축 및 즉시 완료 차감이 일치하는지 확인한다.
11. REWARD_READY 상태가 Unit Shortcut과 교배 화면에 표시되고, 수령은 정확히 1회만 되는지 확인한다.
12. 신규 결과는 해금되고 중복 결과는 pieces 30이 지급되는지 확인한다.
13. 조합표에서 190개 조합과 BREEDING_EXCLUSIVE(MYTHIC 19/20) 각 2% 표기가 보이는지 확인한다.
14. Back 후 기존 탭과 공용 상태바 입력이 정상 복구되는지 확인한다.
15. 1080x1920 및 다른 화면 비율에서 잘림·겹침이 없는지 확인한다.
16. Console error/warning이 새로 발생하지 않는지 확인한다.
