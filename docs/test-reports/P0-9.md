# P0-9 재접속·복구 자동 검증 보고

## 구현

- `BattlePlayerRoster`는 연결 종료 사용자의 Player slot을 예약하고 같은 User ID 재접속만 해당 slot을 회수할 수 있게 한다.
- `BattleWaveStateAuthority`는 플레이어별 `PlayerConnectionState`, User ID, Gold 장부를 Networked 상태로 유지한다.
- `BattleReconnectSnapshotBuilder`는 Board/Alien/Injector/Mutation, Mythic 선택 후보·Timer, Wave/Boss Timer, Monster identity·HP·position을 한 Snapshot으로 캡처한다.
- 실시간 재적용은 별도 클라이언트 JSON을 신뢰하지 않고 Fusion 권위 상태를 사용한다. `FusionKidnapBoardView`와 NetworkObject/NetworkTransform이 재접속 Client의 시각 상태를 reconcile한다.
- Client Monster presentation은 canonical 위치가 갱신된 경우에만 로컬 시점으로 재투영해 한 바퀴 이동 중 사라지는 현상을 방지한다.
