## FeatureTestHub에 필요한 Catalog 필드

각 Case는 다음을 명시해야 한다.

- `taskId`, `title`, `owner`
- `scenePath`, `testType`
- 서버/Balance/계정/Photon 사전조건
- 실행 전 Reset 및 종료 후 Cleanup
- 자동 테스트 assembly/test name
- 사람 검증 체크리스트
- 보고서 경로

초기 Catalog에는 Production Build에 포함되지 않는 격리 Scene만 등록하고, `Battle.unity`는 `Fusion 2-Client` 대상의 공유 실행 진입점으로 참조한다. Hub 자체와 테스트 Scene은 Build Settings에 추가하지 않는다.

## 누락·위험

1. `FeatureTestHub.unity`와 Hub 전용 Editor/Runtime Catalog가 아직 없다.
2. P0-7 UI와 P0-9 재접속은 전용 격리 Scene 및 자동 테스트가 부족하다.
3. 현재 Build Settings에는 `Battle.unity`만 있어 테스트 Scene을 실수로 Production Build에 넣을 위험은 낮지만, Hub 생성 후에도 이 불변조건을 Editor 테스트로 고정해야 한다.
4. Fusion 2클라이언트 입력·재접속·Settlement 전송은 MCP 단독 자동화 범위를 넘을 수 있어 P0-11-6 실행 절차와 사람 Smoke Test가 필요하다.
5. 현재 작업 트리의 Unity/MCP/Balance 로컬 변경은 이 조사에서 수정하거나 stage하지 않았다.
