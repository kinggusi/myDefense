## Daily Result 운영 게이트

이 Development 세션의 runId는 `dev:<Session>`이며 서버 입장 API가 발급한 runId가 아니다. 일반 roster/Settlement POST를 비활성화하고 `IDailyBattleResultSink` 미주입 상태로 종료 결과를 pending에 유지한다. `result sink is unavailable ... pending (fail-closed)`는 이 실행 방식의 예상 결과다. 기존 사전 Summary나 이 pending 결과를 수동 POST하지 않는다.

User/System의 trusted 입장 문맥/결과 Adapter가 제공되면 Battle은 State Authority CLEARED/FAILED, 마지막 완료 Wave, 서버 응답과 멱등 재전송을 검증한다. 운영 Adapter E2E와 두 담당자의 PASS 전에는 Task를 완료로 바꾸지 않는다.
