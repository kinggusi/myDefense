# P0-11-6 Fusion 2클라이언트 실행·Fixture 초기화 절차

## 목적

Feature Test Hub의 `FusionTwoClient` 케이스를 동일한 세션에서 Host와 Standalone Client로 재현한다. Photon App ID와 API/DB 비밀값은 저장소에 기록하지 않고 각 프로세스의 로컬 환경에서 주입한다.

## 사전 조건

1. Unity Editor에서 `Assets/Scenes/Tests/FeatureTestHub.unity`를 열고 Catalog에서 대상 Battle Scene을 선택한다.
2. `Battle.unity`가 Build Settings의 유일한 활성 Production Scene인지 확인한다. Hub와 `TestGameScene`, `FusionConnectionTest`는 Build Settings에서 제외한다.
3. 로컬 Spring Boot가 필요한 케이스는 `http://localhost:8080`에서 실행하고 canonical Balance manifest와 일치하는지 확인한다.
4. Photon Dev App ID는 Unity의 로컬 Realtime 설정 또는 안전한 환경 주입 경로로만 제공한다.

## Host 실행

별도 PowerShell 창에서 다음 값을 프로세스 범위로 설정한다.

```powershell
$env:MYDEFENSE_FUSION_SESSION = "MyDefense-Dev"
$env:MYDEFENSE_FUSION_ROLE = "host"
$env:MYDEFENSE_FUSION_USER_ID = "dev-host"
```

Unity Editor Play Mode에서 `Start Host`를 누르거나, Host 자동 실행이 활성화된 Battle 진입 경로를 사용한다. 화면/로그에서 세션명, `dev-host`, Local Slot 1, Runner Running을 확인한다.

## Standalone Client 실행

두 번째 PowerShell 창은 Host 창과 분리한다. 같은 세션명과 다른 User ID를 사용한다.

```powershell
$env:MYDEFENSE_FUSION_SESSION = "MyDefense-Dev"
$env:MYDEFENSE_FUSION_ROLE = "client"
$env:MYDEFENSE_FUSION_USER_ID = "dev-client"
& "E:\study\MyDefenseGame\_localbuild\FusionClient\Client.exe"
```

실행 파일 경로가 다른 경우 Hub의 Scene 경로와 동일한 최신 빌드 산출물을 선택한다. Client 화면/로그에서 같은 세션 참가, Local Slot 2, Runner Running을 확인한다.

## 반복 실행 전 초기화

- 두 Runner를 모두 `Stop`한 뒤 Editor Play Mode와 Standalone Client를 종료한다.
- Session 이름에 회차 suffix를 붙이지 않고 재사용할 때는 이전 프로세스가 완전히 종료됐는지 확인한다.
- Battle 보드/Gold/Wave가 이전 실행에서 남지 않도록 Scene을 디스크 기준으로 다시 로드하고, 서버 영구 데이터가 필요한 케이스는 해당 테스트의 fixture reset 절차를 먼저 실행한다.
- 자동화된 EditMode 테스트는 fixture를 자체 생성·정리하며, Fusion 2클라이언트 실행 중에는 DB Entity를 두 프로세스 사이에 공유하지 않는다.
- 동일 계정·동일 요청을 재사용하는 Settlement 검증은 새 `requestId`와 `battleSessionId`를 사용한다.

## 최소 Smoke Checklist

1. Host/Client가 동일 Session에 입장한다.
2. 양쪽 Local Slot이 각각 1/2로 고정된다.
3. 한쪽 Kidnap/Gold/보드 변경이 다른 쪽에 복제된다.
4. Host 종료 후 Client가 연결 종료를 표시한다.
5. 재접속 케이스는 새 Client 프로세스로 실행하고 Snapshot/Settlement 기대값을 기록한다.
6. 종료 후 두 Runner를 모두 중지하고 다음 케이스를 위해 초기화한다.

## 보안 메모

Photon App ID, DB 계정, JWT Secret, 운영 API URL은 이 문서나 Catalog에 기록하지 않는다. `LaunchProfile`의 세션명과 테스트용 User ID는 비밀이 아닌 기본값이며, 실제 App ID와 실행 파일 위치는 로컬 설정/환경변수에서 주입한다.
