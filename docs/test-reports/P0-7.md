# P0-7 Legendary candidate and reroll implementation note

Date: 2026-07-27

The Battle State Authority owns the Legendary-to-Mythic candidate flow. Three
distinct candidates are resolved from canonical balance, stored in Fusion
networked state, and selected through an authority RPC. Free/paid rerolls use
the canonical policy and consume the player's in-game Gold only for paid
rerolls. The choice timeout auto-selects the first candidate on the State
Authority, and inherited Mutation DNA is resolved deterministically.

While a choice is pending, the Kidnap button and local board drag are disabled;
the State Authority also rejects move, merge, injector, and Kidnap requests.
Combat attack/movement consumers are not present in the current P0-7 runtime;
their integration is to be rechecked with P0-8.
