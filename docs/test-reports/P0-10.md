# P0-10 Settlement Summary 계약 검증

## 범위

- `BattleSummary`의 플레이어 슬롯/인게임 Gold ledger 필드
- Kill 장부의 `SupportKill`, `BossKill`, canonical `killGold` 집계
- Unity `BattleSettlementSummary`와 Spring Settlement DTO 간 변환

## 계약

- `MatchState.CLEARED` → `VICTORY`, `FAILED` → `DEFEAT`
- 플레이어 슬롯은 Settlement 변환 시 `{1,2}`를 요구한다.
- `initialInGameGold + inGameGoldEarned - inGameGoldSpent = finalInGameGold`를 요약 seed 생성 시 검증한다.
- `monsterSpecId`별 `totalKills`, `bossKills`, `totalKillGold`를 Kill 장부에서 복사한다.
- `SupportKill`은 Gold를 추가 지급하지 않고 통계 장부에만 반영한다.
- requestId, timestamp, summaryHash는 Battle simulation state가 아닌 Settlement coordinator가 주입한다.

## 구현·자동 검증

- State Authority Gold 장부와 Kill/Support/Boss Kill audit을 `BattleSettlementSummaryBuilder`에 연결했다.
- 연결 종료 시 Player 슬롯을 동일 User ID에 예약하고 Settlement seed의 `abandoned`를 연결했다.
- `BattleSettlementCoordinator`는 terminal Match에서 한 번 전송하고 실패 payload를 pending으로 보관하며 명시적 Retry만 허용한다.
