## 인증 경계

- 현재: `BattleSessionRosterRegistrar` → loopback `/api/dev/battle/session-rosters`
- 적용 환경: Spring `local`/`dev`, Unity `local`/`dev`
- 로컬 E2E 사용자: 명시적인 `dev-*` ID만 local DB 자동 생성
- 운영: `FUTURE_AUTH_REPLACEMENT` 표식의 구현을 JWT principal + matchmaking 검증 Adapter로 교체
- 운영 Adapter 부재 시 fail-closed
- Spring Profile 생략/prod에서는 개발 Controller와 Adapter bean이 생성되지 않음
- 두 참가자는 Session 단위 단일 원자 연산으로 등록되어 경쟁 요청의 slot 혼합을 방지
- 일시 실패는 `RetryRosterRegistration()` 명시적 진입점으로만 재시도
