# 디펜스게임 경제·성장·일일 콘텐츠 기획서

## 1. 문서 목적

본 문서는 디펜스게임의 계정 영구 재화, 왹져 성장, 생체변이 성장, 교배 콘텐츠, 일일 파밍 콘텐츠의 기본 구조를 확정하기 위한 기획 기준서다.

현재 단계에서는 장비·덱·프리셋 등 별도 성장축을 추가하지 않고, 기존 왹져·생체변이·교배 시스템을 중심으로 성장과 재화 소비 구조를 구성한다.

---

## 2. 최종 재화 체계

| 자원 | 성격 | 주요 획득처 | 주요 소비처 |
|---|---|---|---|
| 골드 | 일반 영구 재화 | 전투 보상, 일일 콘텐츠, 퀘스트 | 왹져 강화, 생체변이 강화, 계정 연구소 |
| 젬 | 프리미엄 재화 | 업적, 이벤트, 특수 보상 | 교배 시간 단축, 스킨, 닉네임 변경, 하트 충전, 고급 생체변이 |
| 하트 | 게임 입장 재화 | 시간 회복, 보상, 젬 충전 | 일반 게임 및 일부 파밍 콘텐츠 입장 |
| 왹져 카드 | 특정 왹져 귀속 성장 자원 | 뽑기, 보상 | 해당 왹져 해금 및 강화 |
| 대체 코인 | 범용 카드 대체 자원 | 이벤트, 중복 보상, 상점 | 부족한 왹져 카드 수량 대체 |
| 성장 세포 | 왹져 고레벨 강화 재료 | 일일 파밍 맵 | 고레벨 왹져 강화 및 돌파 |
| 변이 촉매 | 생체변이 고레벨 강화 재료 | 일일 파밍 맵 | 고레벨 생체변이 강화 및 돌파 |

### 재화 명칭 구분

- 전투 중 임시 재화: `inGameGold`
- 계정 영구 골드: `accountGold`
- 프리미엄 재화: `gem`
- 입장 재화: `heart`
- 왹져별 카드 수량: `alienCardCount`
- 범용 대체 자원: `substituteCoin`

`inGameGold`와 `accountGold`는 저장 위치와 사용처가 완전히 다르므로 DTO와 Unity 변수에서도 반드시 구분한다.

## 3. 재화 소비처

| 소비처 | 소비 재화 | 역할 |
|---|---|---|
| 왹져 강화 | 왹져 카드 + 골드 | 기본 영구 성장 |
| 카드 부족 대체 | 대체 코인 + 골드 | 카드 부족분 보완 |
| 고레벨 왹져 강화 | 카드 + 골드 + 성장 세포 | 후반 성장 제한 해제 |
| 교배 시간 단축 | 젬 | 장기 대기 콘텐츠의 편의 기능 |
| 스킨 구매 | 젬 | 비전투 수집 요소 |
| 생체변이 강화 | 골드 | 기본 변이 성장 |
| 고급 생체변이 강화 | 골드 + 변이 촉매, 일부 구간 젬 | 후반 성장 및 선택형 강화 |
| 계정 연구소 | 골드 | 계정 단위 편의·영구 성장 |
| 닉네임 변경 | 젬 | 계정 편의 기능 |
| 하트 충전 | 젬 | 플레이 횟수 회복 |

### 장비 시스템

현재 단계에서는 도입하지 않는다.

장비를 도입하면 장비 종류, 옵션, 등급, 인벤토리, 강화, 장착 UI, 전투 스탯 계산 등 별도 대규모 시스템이 필요하다. 기존 왹져 강화·생체변이·교배만으로도 성장축이 충분하므로 우선 제외한다.

## 4. 왹져 강화 구조

### 기본 강화

- 왹져 카드는 특정 왹져에 귀속된다.
- 강화에는 해당 왹져 카드와 골드가 필요하다.
- 카드가 부족하면 부족한 수량만큼 대체 코인을 사용할 수 있다.

예시:

```text
강화 요구 카드: 10장
보유 카드: 7장
대체 코인: 3개
골드: 1,000
→ 강화 가능
```

### 고레벨 강화

일정 레벨 이후에는 일일 파밍 콘텐츠에서 획득하는 `성장 세포`를 추가로 요구한다.

예시 구조:

```text
1~10레벨: 카드 + 골드
11~20레벨: 카드 + 골드 + 성장 세포
21레벨 이상: 카드 + 골드 + 성장 세포 대량 또는 돌파 조건
```

초기 MVP에서는 성장 세포를 하급·중급·상급으로 분리하지 않고 단일 재료로 운영한다.

### 전투 내 등급과 영구 레벨 분리

- 계정 영구 성장: 왹져 레벨
- 전투 중 성장: Merge 등급

두 값은 별도 개념으로 관리한다.

```text
영구 레벨: 15
전투 Merge 등급: NORMAL → RARE → EPIC
```

## 5. 생체변이 강화 구조

### 기본 강화

- 일반 강화는 골드 중심으로 진행한다.
- 일정 단계 이후 변이 촉매를 추가로 요구한다.
- 젬은 매 강화마다 강제하지 않고 고급 구간, 돌파, 옵션 확정 등에 제한적으로 사용한다.

예시 구조:

```text
1~5레벨: 골드
6~10레벨: 골드 + 변이 촉매
특정 돌파 단계: 골드 + 변이 촉매 + 젬
```

### 권장 젬 사용 방식

- 고급 단계 돌파
- 변이 옵션 재설정
- 특정 변이 확정
- 일부 옵션 잠금

젬 없이는 기본 성장이 완전히 막히는 구조는 피한다.

---

## 6. 계정 연구소

계정 연구소는 골드의 장기 소비처다.

### 권장 연구 항목

- 시작 `inGameGold` 증가
- 하트 최대치 증가
- 하트 회복 시간 감소
- 교배 기본 시간 감소
- 왹져 강화 골드 비용 소폭 감소
- 일일 파밍 보상 소폭 증가
- 상점 무료 갱신 횟수 증가

계정 연구소는 공격력·체력 같은 직접 전투 스탯을 크게 올리기보다 편의와 성장 효율 중심으로 설계한다.

## 7. 교배 콘텐츠

### 기본 구조

```text
신화 등급 A 왹져 + 신화 등급 B 왹져 선택
→ 교배 슬롯 등록
→ 48시간 대기
→ 보상 수령
```

### 부모 왹져 처리

- 부모 왹져는 소모하지 않는다.
- 부모 왹져는 잠그지 않는다.
- 교배 중에도 전투 및 다른 콘텐츠에서 사용할 수 있다.
- 제한은 왹져가 아니라 교배 슬롯에 둔다.

### 슬롯 구조

- 기본 교배 슬롯 1개
- 교배 진행 중에는 새 교배 시작 불가
- 젬으로 남은 시간 단축 가능
- 향후 추가 슬롯 해금 가능

### 결과 보상

- 교배 전용 신화 왹져
- 일반 신화 왹져
- 중복 시 해당 왹져 카드 지급
- 장기적으로 교배 포인트 또는 천장 시스템 검토

### 추천 보상 구조 예시

```text
일반 신화 보상: 80%
교배 전용 신화 보상: 20%
교배 완료 시 교배 포인트 1 지급
교배 포인트 10개로 전용 신화 확정 획득 가능
```

확률과 수치는 추후 밸런싱 단계에서 조정한다.

### 시간 단축 비용

남은 시간에 비례해 젬 비용이 감소하도록 설계한다.

```text
48시간 남음 → 젬 100
24시간 남음 → 젬 50
1시간 남음 → 젬 3
```

## 8. 일일 1인 파밍 콘텐츠

### 목적

- 왹져 고레벨 강화 재료 공급
- 생체변이 고레벨 강화 재료 공급
- 1인 플레이 기반의 안정적인 일일 성장 루프 제공

### 콘텐츠 구조

```text
메인 화면
→ 일일 탐사
→ 파밍 맵 선택
→ 스테이지 선택
→ 1인 전투
→ 클리어 보상 지급
→ 일일 횟수 차감
```

### 파밍 맵 2종

| 콘텐츠 | 주요 보상 | 전투 특징 |
|---|---|---|
| 배양 구역 | 성장 세포 | 다수의 약한 적 중심 |
| 변이 연구소 | 변이 촉매 | 상태 이상·보스 중심 |

### 스테이지 구조

초기 MVP에서는 각 파밍 맵 5개 스테이지로 구성한다.

```text
Stage 1 → 기본 재료 소량
Stage 2 → 기본 재료 증가
Stage 3 → 중간 난이도·보상 증가
Stage 4 → 고난이도·보상 증가
Stage 5 → 최고 난이도·최대 기본 보상
```

재료 등급을 나누지 않고 상위 스테이지일수록 동일 재료의 지급 수량을 늘린다.

### 입장 정책

추천안:

- 각 파밍 맵 하루 3회 무료
- 추가 입장 시 하트 소비
- 최초 클리어 보상 별도 제공
- 클리어한 스테이지만 소탕 가능

### 보상 정책

완전 랜덤 보상은 피하고 기본 보상을 확정 지급한다.

```text
기본 보상: 성장 세포 10개 확정
추가 보상: 성장 세포 0~3개 랜덤
```

### 실패 정책

구현 전 아래 중 하나를 확정해야 한다.

- 전투 시작 시 입장 횟수 차감
- 클리어 시 입장 횟수 차감
- 패배 시 일부 반환

추천은 악용 방지를 위해 시작 시 차감하되, 서버 장애나 매칭 실패는 반환 처리하는 방식이다.

## 11. MVP 범위

### 우선 구현

- 계정 잔액 조회
- 골드·젬·하트 구분
- 왹져 카드 + 골드 강화
- 대체 코인으로 카드 부족분 보완
- 성장 세포 1종

- 고레벨 왹져 강화 재료 연결

- 교배 시간 단축

- 계정 연구소
- 스킨
- 닉네임 변경
- 하트 젬 충전
- 소탕 기능

### 현재 제외

- 장비 및 장비 강화

## 12. 핵심 원칙

1. 서버가 모든 영구 재화와 보상 결과의 최종 권한을 가진다.
2. 클라이언트는 잔액을 임의 계산하지 않고 서버 응답으로 갱신한다.
3. `inGameGold`와 `accountGold`를 절대 혼용하지 않는다.
4. 왹져 카드와 대체 코인은 일반 재화와 분리한다.
5. 고레벨 강화 재료는 일일 파밍 콘텐츠에서 공급한다.
6. 교배 부모 왹져는 소모하거나 잠그지 않고 슬롯만 점유한다.
7. 젬은 필수 기본 성장보다 편의·선택·고급 성장에 사용한다.
8. 장비 같은 신규 성장축보다 기존 시스템의 깊이를 우선한다.
## Battle 행성 보상 정책 (8-1 보완)

일반 협동 전투는 행성별 80 Wave를 기준으로 한다. 보상은 현재 시도 중인 Wave가 아니라 `highestClearedWave`(완전히 클리어한 마지막 Wave)를 기준으로 계산한다. `failedAtWave`는 실패가 발생한 Wave를 감사·분석용으로 보존한다.

| 체크포인트 | Gold | 대체 코인(`universalPiece`) |
|---:|---:|---:|
| 10 | 500 | 10 |
| 20 | 750 | 15 |
| 30 | 1,000 | 20 |
| 40 | 1,500 | 25 |
| 50 | 2,000 | 30 |
| 60 | 2,500 | 35 |
| 70 | 3,000 | 40 |
| 80 | 4,000 | 50 |

체크포인트는 행성별 최초 1회만 지급한다. 행성 최초 80 Wave 클리어 젬은 해왕성 3,000, 천왕성 4,000, 토성 5,000, 목성 6,000, 화성 7,000, 지구 8,000, 금성 9,000, 수성 10,000, 태양 11,000이다. 재클리어에서는 최초 보상을 반복 지급하지 않고 반복 승리 Gold만 지급한다.

실패 Gold는 `min(80%, (highestClearedWave / 80)^1.5)` 비율을 적용한다. Wave 10 미만 실패는 영구 보상을 지급하지 않는다. 관전자·탈락자는 종료 시 남아 있으면 지급하고, 명시적 이탈 또는 120초 이상 미복귀는 제외한다. 태양은 잠금 대신 극고난도 콘텐츠로 운영하며 캠페인 전체 완료 보상은 후속 확정으로 남긴다.
