# 신화 교배 정책

## 핵심 계약

- 로비의 독립 콘텐츠이며 Battle Runtime의 Merge·편성 개념과 무관하다.
- 전체 교배 화면은 공통으로 하나만 사용하며 `내 유닛` 탭의 `신화 교배` Shortcut으로만 진입한다.
- 상점과 메인에는 중복 Shortcut을 두지 않고, 슬롯 해금·가속·수령은 모두 `신화 교배` 화면 안에서 처리한다.
- 신화 20종 중 1~18은 일반 신화, 19~20은 교배 전용 신화다.
- 서로 다른 보유 신화 `UserAlien` 2개를 부모로 선택한다.
- 부모는 소모되지 않으며 전투·강화·레벨업·상세 조회에 아무 제한도 받지 않는다.
- 같은 `UserAlien`은 수령 전까지 다른 교배 슬롯의 부모로 중복 참여할 수 없다.
- 부모 순서는 무시한다. `신화 1 + 신화 2`와 `신화 2 + 신화 1`은 같은 조합이다.
- `start`, `claim`, `unlock`, `accelerate`의 `requestId`는 사용자 단위 멱등 키다. 동일 키의 같은 요청은 저장된 최초 응답을 반환하고, 다른 슬롯·부모·작업·가속량에 재사용하면 충돌로 거부한다.

## 슬롯과 시간

- 슬롯 1: 기본 해제
- 슬롯 2: 계정 레벨 30 또는 다이아 5,000으로 영구 해제
- 슬롯 3: 다이아 10,000으로 영구 해제
- 처리 시간: 24시간
- 단축: 10분당 다이아 100, 남은 단위는 올림
- 화면에는 서버 UTC 완료 시각 대신 남은 시간을 `HH:MM:SS`로 표시한다.
- 시간이 끝나도 직접 수령하기 전에는 슬롯과 부모가 해제되지 않는다.

## 결과와 확률

- 20종의 무순서 부모 조합은 총 190개다.
- 각 조합은 고정된 일반 신화 후보 5종을 가진다.
- 일반 후보 5종: 각각 19.2%
- 교배 전용 신화 19: 2%
- 교배 전용 신화 20: 2%
- 결과는 시작 트랜잭션에서 확정하고 수령 전에는 공개하지 않는다.
- 신규 결과는 Lv.1, 조각 0으로 지급한다.
- 중복 결과는 해당 신화 조각 30개를 지급한다.
- 천장 시스템은 최초 출시 범위에서 사용하지 않는다.

## 원천 및 공개 자료

- 원천: `balance/source/balance-data.xlsx`
- 시트: `MythicBreedingConfig`, `MythicBreedingResult`, `MythicBreedingRecipe`
- 공개용 시트: `BreedingCombinationPublic`
- 공개용 이미지: `docs/policies/mythic-breeding-combination-table.png`

Excel에서 JSON을 생성하며 서버는 generated JSON만 읽는다. 공개 이미지는 동일한 Excel 조합 데이터로 함께 생성해 정책과 공지 자료가 어긋나지 않게 한다.
