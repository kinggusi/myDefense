# 상점 1차 정책 — 2026-09-19

사용자가 확정한 P2-6-1 구현 범위. 실제 현금 상품·스킨·패스·하트 판매는 이번 범위가 아니다.

일일 조각 상품은 등급별 1칸이며 해당 등급의 유닛을 서버가 선정한다. 구매 시 화면에 표시된 그 유닛의 조각을 지급한다. 기존 뽑기 확률·조각 지급량·해금 규칙은 변경하지 않는다.

## 럭키 골드 특가

- 계정별 하루 20% 확률로 1칸 등장한다. 당일 출현 여부와 상품은 저장한다.
- 등장 상품은 왹져DNA 20개/30,000골드 또는 성장세포 10개/20,000골드이며 각각 50%다.
- 하루 1회, 두 상품을 합쳐 주 2회 구매할 수 있다.
- 재접속·서버 재시작·카탈로그 재조회는 다시 추첨하지 않는다.

## 광고 품목 새로고침

- 보상형 광고를 성공적으로 완료한 경우 하루 3회까지 가능하다.
- 구매하지 않은 일일 조각 상품만 같은 등급의 다른 유닛으로 바뀐다.
- 럭키가 이미 등장했고 미구매라면 다른 럭키 상품으로 바뀐다. 럭키가 없는 날에는 리롤로 생성하지 않는다.
- 구매 완료 상품과 모든 구매 제한은 유지한다.
- 광고 취소·실패, 잘못된 증명, 만료된 요청에는 리롤 횟수를 차감하지 않는다.
- 실제 광고 제공자 검증이 연결되지 않은 운영 환경에서는 리롤을 비활성화한다. 개발 모의 완료는 명시적으로 켠 로컬 개발 환경에서만 제공한다.

## 저장·가격 확인

- 일일 초기화는 한국 시간 자정, 주간 초기화는 한국 시간 월요일 자정이다.
- 서버가 잔액·가격·구매 한도·상품·광고 완료·리롤 한도를 검증하고 영구 저장한다.
- 확인창 이후 가격이나 상품이 바뀌면 결제하지 않고 새 가격을 다시 확인한다.
- 동일 요청 재전송은 기존 결과를 반환하며 재차 차감하거나 지급하지 않는다.
- 계정 전환 시 다른 계정의 미완료 구매 요청을 보내지 않는다.

## 수치 관리 및 검증

- 원본: `balance/source/balance-data.xlsx`의 `ShopProduct`, `ShopOffer`, `ShopPolicy`.
- 생성 결과: 기존 상점 데이터 및 `shop-catalog.json`. 생성기를 통해 서버·Unity 데이터에 반영한다.
- 구현 → 자동 테스트 → 실제 화면 조작 → 문제 수정·재검증 → 독립 리뷰 순서로 진행한다. 최종 사용자 인수는 별도로 남긴다.
- 마스터 계정 잔액을 임의로 늘리지 않고 격리된 개발 데이터로 구매·재시작 보존을 검증한다.
